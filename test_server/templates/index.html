1. GET 検索フォーム (本文反射)

入力されたキーワードがHTMLエスケープされずにそのまま本文中に出力されます。

python xss_scanner.py --url http://127.0.0.1:5000/search_vuln --param keyword

2. GET 検索フォーム (対策済)

html.escape() により特殊文字がエンティティ変換され無害化されています。

python xss_scanner.py --url http://127.0.0.1:5000/search_safe --param keyword
脆弱 (VULNERABLE)

3. GET 属性値コンテキスト (value="...")

ダブルクォートのエスケープが不完全で、属性値からのタグ抜け出しが可能です。

python xss_scanner.py --url http://127.0.0.1:5000/attr_vuln --param q
対策済 (SANITIZED)

4. GET 属性値コンテキスト (対策済)

クォートを含む完全なエスケープ quote=True が適用されています。

python xss_scanner.py --url http://127.0.0.1:5000/attr_safe --param q
脆弱 (POST VULNERABLE)

5. POST コメント投稿 (脆弱)

POSTメソッドで送信されたコメント本文が生のままHTML出力されます。

python xss_scanner.py --url http://127.0.0.1:5000/comment_vuln --param comment --method POST
対策済 (POST SANITIZED)

6. POST コメント投稿 (対策済)

POSTデータがサーバー側でエスケープ処理されて安全に出力されます。

python xss_scanner.py --url http://127.0.0.1:5000/comment_safe --param comment --method POST
認証付き (SESSION TEST)
